# Veenit Ramteke — Engineering & AI

An original, responsive resume and project portfolio built with semantic HTML and a standalone stylesheet.

## Run locally

Open `index.html` in a browser. Google Fonts need an internet connection; the typography has system fallbacks.

## Sections

- Introduction and current interests
- About and focus areas
- Selected projects: DRISHTI, CarbonLoop, and VASH
- Hackathon highlights
- Contact links

The project visuals use CSS shapes and typography, so there are no image assets or JavaScript dependencies. The layout adapts for mobile, supports keyboard navigation, and respects reduced-motion preferences.
