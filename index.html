— Work

The work

Disaster response · Tabletop demo

DRISHTI

A disaster-response workspace that brings field reports, coverage gaps, routes, and resources into one review process. Missions require human approval, with decision history and offline command reconciliation supporting the workflow.

Stack: React, TypeScript, FastAPI, PostgreSQL / PostGIS.

Supervised tabletop demo; not a live emergency deployment.

View DRISHTI on GitHub ↗

Sustainability · Hackathon MVP

CarbonLoop

A sustainability game that turns everyday activities into missions, progression, and rewards. A deterministic carbon engine keeps estimated avoided emissions separate from game points, while browser storage preserves demo progress.

Web stack: Next.js, React, TypeScript, Tailwind CSS.

Hackathon demo using synthetic activities, simulated evidence, and mock rewards.

View CarbonLoop on GitHub ↗

Transaction monitoring · Hackathon project

VASH

A transaction-monitoring project combining anomaly scoring, graph analysis, and a security operations dashboard to investigate suspicious payment patterns.

Stack: React, TypeScript, FastAPI, Python.

My contribution: Database and data structuring.

Team project for Hack2Ignite 2026.

View VASH on GitHub ↗
